Gem Junction

2023-2024 · Mobile game · iOS & Android

A mobile puzzle game on iOS and Android.

▶ Play
Details
Origin
A classmate dared me to make a copy of a popular game at the time, Suika Game (Watermelon Game), on the web. Later, I expanded it into a unique, full mobile game.
Takeaways
  • Shipping takes more than motivation. A fully localized game with in-app purchases, ads, accounts, achievements, and leaderboards requires determination and a lot of time.
  • App Store review is slow. The App Store Connect submission process is long and tedious. Expect delays and failed submissions.
  • Mobile is saturated. It is nearly impossible to get organic downloads without marketing or App Store Optimization.

ASO, Account management, Development environments, In-App Purchases, Game Center (Achievements, Leaderboards), Localization, collaboration with an artist, build validation
Used
Unity, C#, Unity Gaming Services, Apple Store Connect, Google Play Store, TestFlight
Pong

Pong

2025 · Desktop game · Multiplayer

The classic, rebuilt as a desktop game. Multiplayer proof of concept.

⬇ Mac ⬇ Windows
Details
Origin
A proof of concept to test Unity's ECS networking. It is powerful and can handle a huge number of objects, and I wanted to find out whether I'd want to build a full-scale multiplayer project with it.
Takeaways
  • Multiplayer exponentially complicates development. Even a game as simple as Pong gets much harder once every action has to stay in sync between players.
  • Prototype the tech before committing. Building something small and familiar let me judge ECS networking itself before betting a full-scale project on it.
Learned
Entity Component System (ECS), networking fundamentals
Used
Unity, C#

Fleetword

2026 · Web game

A tool to improve typing, spelling, and vocabulary.

Details
Origin
Created to improve my vocabulary, but evolved into a more comprehensive tool.
Takeaways
  • I designed, Claude built. I made the decisions about what to build and why, and used Claude as technical support to write the code. That let me try ideas in real time and iterate quickly as my needs changed.
  • Design starts with how people learn. Most of my effort went into thinking about how people actually pick up typing, spelling, and vocabulary, and shaping the features around that.
  • Learning has to stay fun. The hardest design problem was balance: enough practice to improve, and enough fun to keep coming back.
